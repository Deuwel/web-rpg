## 0. 문서의 지위

본 문서는 2026-11-06까지 사용자가 승인한 방향과 수정 사항을 통합한 개발 기준이다. 기존 WEB_RPG_BASELINE_v0.1 초안보다 본 문서의 최신 규칙을 우선한다. 구현 지침과 검증 기준은 [개발 가이드라인](DEVELOPMENT_GUIDELINES.md)을 함께 참조한다.

- **확정**은 사용자의 명시적 요구 또는 후속 승인으로 채택한 규칙이다.
- **채택 초안**은 승인받은 설계의 출발값이다. 수치와 세부 밸런스는 플레이테스트로 조정하고 변경 이력을 남긴다.
- **제안 / 미정**은 아직 사용자 결정이 없거나 이번 통합 과정에서 연결을 위해 제시한 내용이다. 확정된 게임 규칙처럼 공개하지 않는다.
- 수치가 명시되지 않은 스킬의 피해 계수, MP 비용, 쿨타임, 중첩 제한은 미정이다.
- 기획에 포함된 기능과 실제 구현 완료 상태는 구별한다. 본 버전은 기획 기준이며 완성된 게임을 뜻하지 않는다.

## 1. 정체성과 핵심 경험

임시 제목은 **RE:RPG**다. 아이템 파밍, 전술 구성, 여러 단계의 Prestige로 성장하는 싱글플레이 웹 RPG를 지향한다. 데스크톱과 모바일 브라우저를 지원한다.

특출난 장점이 없던 모험가가 시간을 되돌리는 힘을 깨닫고, 신체를 재구성하고, 나아가 세계의 환경까지 바꾸는 이야기다. 죽음과 회귀 능력의 발견이라는 세계관 모티프는 활용할 수 있으나, 실제 회귀 실행은 조건 달성 후 플레이어가 선택한다.

핵심 경험은 같은 장비에서도 품질과 잠재능력을 비교하는 파밍, 직업과 페르소나로 달라지는 전투, 초기화 이후 달라지는 성장, 그리고 도형만으로도 읽히는 타격감이다.

기본 흐름은 마을 정비 → 던전 선택 → 일반 전투와 장비 획득 → 보스 도전 → 다음 마을 → 회귀 또는 환생 → 영구 성장이다. L3 개변 이후에는 자원 생산과 세계 개변 중심으로 전환된다.

## 2. 세계관과 마을 / 던전 진행

### 2.1 지역 규칙 | 확정

- 마을마다 연결된 던전 수를 다르게 설정할 수 있다.
- 다음 마을의 조건은 지정 레벨과 이전 마을의 지정 최고 난이도 던전 클리어다. 모든 이전 던전 클리어를 요구하지 않는다.
- 던전 번호, 권장 레벨, 선행 조건, 대표 드롭을 데이터로 관리한다.
- 최초 L1 회귀에는 현재 레벨 50 이상과 전체 10번째 던전 클리어를 모두 요구한다.
- 10번째 던전은 세 번째 마을의 네 번째이자 마지막 던전이며 50레벨 던전이다.
- 천 장비는 첫 마을의 파밍 지역부터 획득할 수 있다.

### 2.2 이야기와 명칭

| 마을 | 이야기 | 연결 던전 |
|---|---|---|
| 윈드해븐(Windhaven) 마을 | 알카논 유적의 이상현상을 조사한다 | 변두리 들판 / 돌핀 언덕 / 알카논 유적 |
| 아르카디아 부락 | 본격적인 모험을 떠나 폐쇄적인 숲속 엘프 부락의 문제를 해결한다 | 침묵의 숲 / 버려진 제사장 / 시련의 전당 |
| 세 번째 마을 | 이름과 이야기는 미정 | 네 던전. 마지막 던전에서 최초 회귀 조건을 완성 |

윈드해븐, 돌핀 언덕, 알카논 유적, 아르카디아, 버려진 제사장, 시련의 전당은 사용자 지정 이름이다. 변두리 들판과 침묵의 숲은 기존 초안의 유지 후보다. **버려진 제사장**은 사용자 제공 표기를 그대로 사용한다.

첫 세 마을의 3 / 3 / 4 배치는 기존 이름과 10번째 던전 조건을 연결한 구성 초안이다. 이후 마을에도 같은 수를 강제하지 않는다.

| 전체 던전 번호 | 마을 내 순서 | 권장 레벨 초안 |
|---|---|---:|
| 1~3 | 윈드해븐 1~3 | 5 / 10 / 15 |
| 4~6 | 아르카디아 1~3 | 20 / 25 / 30 |
| 7~10 | 세 번째 마을 1~4 | 35 / 40 / 45 / 50 |

레벨 1부터 첫 던전에 진입할 수 있는 튜토리얼 동선을 둔다. 첫 두 마을의 진입 레벨, 각 던전의 세부 선행 조건은 콘텐츠 설계에서 확정한다. 5레벨 간격의 던전 배치는 제안이며 장비의 5레벨 단위 규칙과 구별한다.

### 2.3 던전 내부 | 제안

일반 전투 10회 승리 후 해당 던전 보스 도전이 열리는 구성을 시작점으로 둔다. 일반 적은 1~3명이 동시에 등장할 수 있다. 보스도 동시 전투원 상한 3명 안에서 단독 또는 부하 동반 구성을 사용한다.

보스는 별도 도전 버튼을 제공하고, 반복 일반 파밍을 허용한다. 영구 최초 처치 보상과 회차별 클리어 기록을 분리한다. 사망 후 복귀 위치와 비용은 미정이며 사망 이벤트에서 프레스티지를 자동 실행하지 않는다.

## 3. 전투와 전술

### 3.1 속도 기반 시간축 턴제 | 확정

각 전투원은 독립적인 행동 게이지를 가진다. 게이지가 최대치에 도달하면 차례를 얻고 하나의 행동을 순차 처리한다. 속도가 빠르면 더 자주 행동한다.

채택 초안의 기본 게이지 최대량은 100, 속도 100의 기본 행동 간격은 2초다.

`초당 충전량 = 유효 속도 / 2`

`기본 행동 간격(초) = 2 × 유효 게이지 최대량 / 유효 속도`

목걸이 등으로 최대 게이지가 감소하면 같은 속도에서도 차례가 빨리 온다. 일반 행동 간격의 실험 범위는 0.5~5초다. 상한과 하한은 밸런스 데이터에 둔다.

동시 도달은 플레이어 우선, 적은 안정적인 순서로 처리한다. 먼저 쓰러진 대상의 행동은 취소한다. 속도 변경은 쌓인 게이지를 유지한 채 충전 속도에 반영한다. 최대 게이지 변경 시 충전 비율 유지 여부는 구현 전 정할 항목이다.

추가 행동권, 영창, 적 게이지 정지처럼 페르소나가 만드는 예외는 8장의 고유 규칙으로 처리한다. 화면 애니메이션 길이는 실제 판정과 행동 횟수를 바꾸지 않는다.

### 3.2 조작 | 확정 및 채택 초안

- 기본 공격과 등록된 스킬은 자동 실행된다. 자동 스킬은 시작부터 제공한다.
- 스킬은 원칙적으로 자신의 차례를 사용한다. 예외는 개별 스킬과 페르소나 설명에 명시한다.
- 기본 방어 명령은 제외하고 철벽 자세 같은 개별 스킬로 방어한다.
- **포션 슬롯은 2칸**이다. 등록 포션은 행동 차례와 독립적으로 수동 사용하며 종류별 쿨타임을 가진다.
- 포션의 쿨타임 공유 범위와 같은 포션의 중복 등록은 미정이다.
- 정지 명령의 이름은 **일시정지**다. 정지 시 전투 시간 기반 게이지, 지속 효과, 쿨타임을 함께 멈추는 안을 채택 초안으로 둔다.
- 적 선택, 다음 차례 스킬 예약, 예약 취소와 후퇴를 제공하는 안을 유지한다. 예약 실행 직전에 자원과 대상 유효성을 다시 확인한다.
- 예약 불가 시 이유를 알리고 자동 전술로 복귀하는 방식은 연결 제안이다.
- 후퇴 시 이미 확정된 보상을 보존하고 현재 미획득 보상을 포기한다.
- 보스의 강한 행동은 이름, 대상, 진행 표시로 예고한다.
- 초기에는 백그라운드 전투를 일시정지하고 복귀 후 명시적으로 재개한다. 오프라인 보상은 후속 정책 결정 대상이다.

### 3.3 전술 선택 규칙 | 확정

스킬 슬롯마다 발동 조건과 우선순위를 설정한다. 우선순위는 같은 값을 허용하며 작은 숫자가 먼저다.

1. 배운 스킬이며 현재 직업, 장비, 자원, 쿨타임, 대상 조건을 만족하는지 확인한다.
2. 발동 조건이 있는 스킬은 조건을 만족해야 후보가 된다. 조건 없음은 항상 후보가 될 수 있다.
3. 후보 중 우선순위 숫자가 가장 작은 그룹을 선택한다.
4. 그 그룹에서 조건을 만족한 조건부 스킬을 무조건 스킬보다 우선한다.
5. 여전히 같으면 슬롯 배치 순서대로 선택한다.
6. 후보가 없으면 기본 공격을 한다. 영창이나 조준 등 전용 상태에서는 해당 페르소나의 대체 행동 규칙을 적용한다.

| 슬롯 | 우선순위 | 스킬 | 조건 |
|---|---:|---|---|
| 1 | 1 | 전투의 함성 | 해당 버프 미적용 |
| 2 | 2 | 가르기 | 없음 |
| 3 | 2 | 휩쓸기 | 생존한 적 3명 이상 |

함성이 사용 가능하고 버프가 없으면 함성을 사용한다. 버프가 적용된 뒤에는 적이 3명이면 휩쓸기, 적이 1~2명이면 가르기를 사용한다. 동일 우선순위에서 조건부 두 스킬이 모두 만족하면 앞 슬롯이 먼저다. 우선순위가 다른 경우에는 숫자 우선 규칙을 먼저 적용한다.

기본 조건은 자신의 HP 또는 MP가 N% 이하, 버프 미적용, 생존한 적 수가 N명 이상 또는 이하를 포함한다. 페르소나별로 분노, 탄창, 조준 단계, 영창, 죽음의 유예, 지연 피해 비율, 선고량, 기적 상태를 추가한다. N은 유효 범위 안에서 편집하고 적용 결과를 표시한다.

### 3.4 전투 능력치와 특수 스탯

기본 전투 능력치는 최대 HP, 최대 MP, 물리 공격력, 마법 공격력, 물리 방어력, 마법 저항력, 속도, 치명타 확률, 치명타 피해다.

| 특수 스탯 | 의미 | 구체화 방향 |
|---|---|---|
| 흡혈 | 실제로 가한 피해에 비례해 HP 회복 | 초과 피해를 제외한다. 스킬별 발동 가능 여부와 효율을 명시 |
| 물리 관통 / 마법 관통 | 해당 방어 수치 일부 무시 | 고정 관통과 비율 관통의 적용 순서는 미정 |
| HP / MP 자연 회복 | 전투 시간 경과에 따른 회복 | 고정값과 최대 자원 비율을 구별 |
| 보스 추가 피해 | 보스 태그가 있는 적에게 주는 피해 증가 | 일반 부하에게는 보스 효과를 적용하지 않음 |
| 회복 효과 | 직접 시전하는 회복 스킬의 회복량 증가 | 포션과 흡혈 적용 여부는 개별 정의 |
| 보호막 효과 | 부여하는 보호막량 증가 | 보호막 중복, 교체, 상한은 스킬 데이터로 정의 |
| 온힛 효과 | 지정 타격 적중 시 발생하는 추가 효과 | 발동 계수, 횟수 제한, 재발동 가능 여부를 명시 |
| 게이지 최대량 감소 | 행동에 필요한 게이지 감소 | 속도와 별도 효과로 표시. 최소 간격과 함께 조정 |

능력치 상세 창은 초기값, 스탯 투자, 장비, 스킬, 마스터리, 프레스티지 기여를 출처별로 보여준다. 특히 기본 / 장비 / 스킬은 다른 색과 텍스트 라벨을 함께 사용한다.

### 3.5 피해 계산 | 채택 초안

`기본 피해 = 해당 타격 공격력 × 행동 계수`

`방어 적용 피해 = 기본 피해 × 100 / (100 + 유효 방어 수치)`

이후 치명타, 보스 추가 피해 등 피해 증가와 최종 피해 감소를 적용하고 최종 단계에서 정수화한다. 유효 방어는 0 이상, 일반 유효 공격의 최소 피해는 1이다. 무적과 완전 차단은 0 피해를 허용한다. 물리는 물리 방어력, 마법은 마법 저항력을 사용한다.

기본 치명타 확률 5%, 피해 배율 150%로 시작한다. 쌍수는 타격별로 치명타를 판정한다. 혼합 피해는 물리와 마법 성분을 각각 해당 방어로 처리한 뒤 합친다. 합산 및 곱연산 그룹, 관통 순서, 지속 피해의 치명타와 흡혈은 개별 수치 설계에서 확정한다.

## 4. 도형 전장과 UI

### 4.1 시각 방향 | 확정

**기본 도형과 CSS를 이용한 전장형**을 채택한다. 깔끔한 네온 스타일이며 The Tower는 분위기 참고다. 캐릭터는 닉네임으로 표시한다. 원, 삼각형, 마름모, 고리 등을 조합하여 적의 유형과 상태를 구별한다.

일러스트 카드와 정보 카드형 전투안은 채택 대상에서 제외했다. 기존 이미지 시안은 제작 리소스로 사용하지 않는다. 게임 전장과 UI는 추가 래스터 이미지 없이 제작한다.

텍스트 연결에는 가운뎃점 대신 `|`를 우선한다. **재화 표시는 예외**이며 재화 전용 아이콘과 보유량을 쌍으로 배치하고 항목 간 여백으로 구분한다. 아이콘을 누르거나 포커스하면 이름을 확인할 수 있다.

### 4.2 공격과 피격

| 순간 | 표현 | 시작값 |
|---|---|---|
| 공격 준비 | 공격자 강조와 상대 방향의 짧은 이동 | 60~100ms |
| 물리 적중 | 방향성 있는 베기 또는 충돌선 | 80~140ms |
| 마법 적중 | 발사체, 파동, 짧은 빛 확산 | 120~200ms |
| 피격 | 대상만 짧게 흔들고 밝기 변화 | 전장 전체 흔들림은 절제 |
| 피해 숫자 | 크게 등장하고 위로 떠오른 뒤 사라짐 | 600~900ms |
| HP | 실제 HP를 즉시 반영하고 손실 잔상 바가 추격 | 200~350ms |
| 치명타 | 큰 숫자, 별도 표식과 색 | 일반 타격과 구분 |
| 회복 / 보호 | 전용 기호와 수치 | 색 이외 단서 제공 |
| 처치 | 도형 붕괴 또는 페이드와 드롭 표시 | 보상 확정 후 연출 |

슬롯 순서와 전투원 위치는 안정적으로 유지한다. 적 1~3명과 플레이어가 동시에 읽혀야 한다. 죽은 적의 퇴장과 새 웨이브 등장으로 남은 보상 표시를 유실하지 않는다.

### 4.3 숫자 표시 | 확정

수치 축약은 **기본 OFF**다. 예를 들어 125,400은 그대로 표시하며 설정에서 축약을 켤 수 있다. 축약은 표현만 바꾸고 계산값을 바꾸지 않는다.

공격과 피격 숫자는 출발 영역을 구분하고, 쌍수는 두 타격을 순서대로 표시한다. 위치를 순환해 겹침을 줄이고 화면 효과 수를 제한한다. 연출 간소화 옵션에서도 실제 피해와 상태 변화는 표시한다.

L4 수준의 매우 긴 숫자는 전체 표시 설정을 존중하면서 상세 확장 영역이나 내부 스크롤 등으로 접근 가능하게 해야 한다. 기본 화면에서 긴 숫자를 수용하는 최종 방식은 미정이며 강제로 축약 ON으로 바꾸지 않는다.

## 5. 장비와 제작 시설

### 5.1 슬롯과 역할 | 확정

총 9슬롯은 투구, 갑옷, 바지, 신발, 무기, 보조무기, 반지1, 반지2, 목걸이다.

| 부위 | 주요 역할 |
|---|---|
| 투구 / 갑옷 / 바지 / 신발 | HP, MP, 방어력 |
| 무기 / 보조무기 | 공격력, 특수 스탯, 추가 타격 또는 지원 |
| 반지1 / 반지2 | 특수 스탯과 전반적인 능력치 |
| 목걸이 | 행동 게이지 최대량 감소 같은 특수 능력 |

반지 같은 종류 두 개 착용은 기존 초안의 제안으로 유지한다. 고유 효과의 중복 제한은 아이템 데이터로 정한다.

### 5.2 방어구 | 확정

같은 레벨, 등급, 품질의 기본 생존력은 중갑 > 경갑 > 천이다. 중갑은 HP와 방어력 중심이며 **속도 페널티를 적용**한다. 경갑은 물리 보너스, 천은 마법 보너스와 MP 운용을 지원한다. 첫 마을부터 세 타입 모두 획득할 수 있다.

부위별 혼합 착용을 허용한다. 중갑 속도 페널티의 수치와 합산 방식은 미정이다. 방어구 마스터리는 실제 착용한 해당 타입 부위에 적용한다.

### 5.3 무기 구성과 쌍수 | 확정 및 채택 초안

양손은 주무기와 보조 슬롯을 함께 사용한다. 한손 두 자루는 주무기와 보조 슬롯에 장착하여 한 차례에 두 번 공격한다. 방패와 일부 마법 보조구는 공격하지 않는다.

- 주무기는 자기 무기의 공격력 100%, 보조무기는 자기 무기의 공격력 60%로 시작한다.
- 두 무기의 공격력을 합쳐 각 타격에 중복 적용하지 않는다.
- 한 차례 안에서 주무기 후 보조무기 순서로 처리한다.
- 첫 타격으로 대상이 죽으면 둘째 타격은 취소한다. 일반 쌍수의 둘째 타격을 다른 적에게 옮기지 않는다.
- 스킬의 타격 수와 온힛 계수는 별도로 정의한다.
- 도적의 쌍수 숙련 등은 기본 보조 계수를 명시적으로 수정한다.
- 위 규칙은 **게임 내 도움말과 장비 비교에 표시**한다.
- 양손 장착 시 기존 보조무기를 인벤토리로 옮긴다. 공간 부족 시 전체 교체를 취소한다.

무기 타입 채택 초안은 한손검, 양손검, 단검, 활, 지팡이, 마도서, 방패다. 한손검과 단검은 쌍수 가능, 양손검과 활과 지팡이는 양손, 마도서와 방패는 비공격 보조다. 마도서를 함께 쓸 한손 마법 주무기는 추가 검토 대상이다.

장비는 클래스보다 무기와 스킬의 요구 조건을 중심으로 제한한다. 모든 페르소나 조합에 실제 사용 가능한 무기와 스킬 구성이 있어야 한다.

### 5.4 레벨과 등급 | 확정

장비 레벨은 5레벨 단위다. 레벨 1~4용 시작 장비를 별도 제공하는 안을 유지한다. 장착 제한은 현재 레벨을 기준으로 한다.

| 등급 | 잠재능력 줄 수 | 강화 보너스 배율 초안 |
|---|---:|---:|
| 일반 | 0 | 1.00 |
| 고급 | 1 | 1.05 |
| 희귀 | 1 | 1.10 |
| 영웅 | 2 | 1.15 |
| 전설 | 3 | 1.20 |
| 신화 | 4 | 1.25 |

상위 등급은 기본 능력치도 더 높다. 기본 능력치 등급 배율과 강화 보너스 배율은 별개 데이터다. 기본 등급 배율은 미정이다.

### 5.5 품질 | 확정

품질 Q는 0~100%이며 통상 기본 능력치에 80~120%를 적용한다.

`품질 배율 = 0.8 + 0.004 × Q`

기본 능력치 100이면 품질 0 / 50 / 100에서 각각 80 / 100 / 120이다. 품질은 레벨과 등급으로 정한 기본 능력치에 적용한다. 잠재능력, 소켓 수, 목걸이의 규칙 변경 효과에 대한 품질 적용은 별도 명시하며 임의로 확대하지 않는다.

### 5.6 장비 생성과 비교 | 제안

장비 템플릿과 개별 획득 인스턴스를 분리한다. 종류와 레벨 → 등급 → 품질 → 잠재능력 종류와 수치 순서로 생성한다. 품질과 잠재능력은 독립이다.

장비 비교에서 기본 능력치, 품질, 강화, 잠재능력, 무기 공격 횟수, 중갑 속도 페널티, 고유 효과를 함께 보여준다. 단일 전투력만으로 우열을 확정하지 않는다.

### 5.7 잠재능력 | 확정

잠재능력 자체의 별도 등급은 생성하지 않는다. 줄 수와 수치 범위는 장비 등급과 레벨 제한을 따른다. 같은 레벨에서는 상위 등급의 옵션 수치 범위가 높다.

많은 골드와 혼돈 파편으로 재설정할 수 있다. 일부 줄을 잠그면 그 줄의 종류와 수치를 보존하고 나머지만 재추첨한다. 잠긴 줄이 늘수록 비용은 기하급수적으로 증가한다.

비용 제안은 각 재화별로 `기본 비용 × 잠금 배율^잠긴 줄 수`다. 배율, 비용표, 중복 옵션 허용, 전 줄 잠금 처리, 일반 등급의 재설정 버튼 처리는 미정이다. 실행 전에 비용과 보존 줄을 보여준다. 장비의 판매 방지 잠금과 잠재능력 줄 잠금은 다른 상태다.

### 5.8 재련과 강화 | 확정 및 채택 초안

| 기능 | 비용 | 결과 |
|---|---|---|
| 기본 재련 | 골드 + 강화석 | 품질 −10~+10%p |
| 고급 재련 | 골드 + 혼돈 파편 + 동일 등급의 동일 장비 1개 | 품질 0~+15%p |
| 강화 | 골드 + 강화석 | 강화 단계별 기본 능력치 증가 |
| 잠재능력 재설정 | 많은 골드 + 혼돈 파편 | 잠그지 않은 잠재능력 재추첨 |

재련은 품질 수치에 퍼센트포인트를 더하고 결과를 0~100% 안으로 제한하는 안이다. 예를 들어 품질 70에서 기본 재련은 60~80, 고급 재련은 70~85다. 고급 재련의 동일 장비는 같은 템플릿과 등급을 뜻하는 제안이며 레벨 제한 일치 여부, 소켓과 강화 여부의 조건은 미정이다. 재료의 강화가 대상에 자동 이전되는 규칙은 정의되지 않았다.

일반 최대 강화는 +9다. +k 도전 성공률은 `1 − 0.1 × (k − 1)`이다. 실패해도 파괴되지 않는다. 실패 시 강화 단계 유지 여부와 비용 전액 소비 여부는 **단계 유지 / 비용 소비**를 제안하되 구현 전 확정한다. 목표 단계, 장비 등급, 레벨 제한이 높을수록 비용이 증가한다.

강화는 품질 반영 후의 미강화 기본 능력치 B를 기준으로 계산한다.

`k단계 성공의 추가 보너스 = (k + 4)% × 등급 강화 배율 R`

`누적 강화율 E(k) = R × (k(k + 1)/2 + 4k) / 100`

`강화 후 기본 능력치 = B × (1 + E(k))`

| 목표 강화 | 성공률 | 일반 등급 이번 증가 | 일반 등급 누적 증가 |
|---|---:|---:|---:|
| +1 | 100% | +5% | +5% |
| +2 | 90% | +6% | +11% |
| +3 | 80% | +7% | +18% |
| +4 | 70% | +8% | +26% |
| +5 | 60% | +9% | +35% |
| +6 | 50% | +10% | +45% |
| +7 | 40% | +11% | +56% |
| +8 | 30% | +12% | +68% |
| +9 | 20% | +13% | +81% |

일반 +9는 B의 181%, 신화 +9는 B의 201.25%다. 신화는 B 자체도 등급에 따라 크므로 두 효과가 함께 반영된다. 계산 중 소수점을 보존하고 최종 표시에서 반올림한다.

강화 배율은 기본 능력치에 적용한다. 잠재능력, 룬, 특수 규칙 효과는 해당 데이터의 명시 없이는 강화하지 않는다. 재련으로 품질이 바뀌면 B부터 다시 계산한다. 비용, 성공률, 현재 대비 성공 시 능력치, 실패 결과를 같은 화면에서 확인하게 한다.

### 5.9 소켓과 룬 | 후속 방향

소켓은 0~6개다. 룬을 넣어 빌드를 확장한다. 소켓 생성, 등급별 제한, 제거 비용, 룬 효과, 프레스티지 보존 방식은 미정이다. 데이터에는 슬롯과 장착 룬의 명확한 소유 관계를 마련한다.

## 6. 재화와 파밍

### 6.1 기본 재화 | 확정

| 재화 | 획득 | 소비 |
|---|---|---|
| 골드 | 몬스터 처치, 장비 매각 | 강화, 재련, 잠재능력 재설정 |
| 강화석 | 몬스터 처치 시 낮은 확률, 장비 분해 | 강화, 기본 재련 |
| 혼돈 파편 | 보스 처치 시 낮은 확률, 일반 몬스터 처치 시 매우 낮은 확률 | 고급 재련, 잠재능력 재설정 |

분해 강화석 수량은 장비 강화 단계, 레벨 제한, 등급을 고려한다. 정확한 드롭률, 분해 환급률, 가격은 미정이다. 같은 아이템을 매각과 분해로 중복 소비할 수 없다.

재화는 전투 중 항상 확인할 수 있어야 한다. CSS 아이콘 초안은 겹친 동전, 육각 광석, 갈라진 마름모다. 형태와 접근 가능한 이름으로 구분하고 보유량을 함께 표시한다.

### 6.2 인벤토리 | 기존 초안의 제안 유지

초기 인벤토리는 60칸으로 시험한다. 가득 차면 임시 획득함에 보관하고 다음 전투를 멈춰 획득 아이템을 유실하지 않는다. 정렬, 필터, 장착 비교, 잠금, 일괄 판매와 분해의 대상 확인을 기본 기능으로 제공한다.

보스 장비 1개 이상 보장은 밸런스 제안이다. 던전마다 대표 부위와 등급 범위를 정해 목표 파밍을 지원한다. 자동 판매와 조건별 정리 같은 고급 자동화는 프레스티지 보상에 배치할 수 있다.

보상은 처치된 개체별로 묶는다. 같은 종류의 적 여러 마리를 한 번에 처치해도 각 개체의 경험치, 골드, 재화, 장비 결과를 구분하고 한 번만 지급한다.

## 7. Prestige

### 7.1 레이어 | 확정

| 계층 | 이름 | 조건 | 보상과 성장 |
|---|---|---|---|
| L1 | 회귀 | 현재 레벨 50 이상 + 전체 10번째 던전 클리어 | 시간 파편으로 능력치와 일부 편의 업그레이드 |
| L2 | 환생 | 이번 환생 회차의 시간 파편 획득 누계가 N 이상 | 에테르로 환생 트리 성장 |
| L3 | 개변 | 이번 회차의 에테르 획득 누계가 100만 이상 | 매터와 자원 자동 생산, 세계 환경 개변 |
| L4 | 창조 | 시간 파편 1e308개와 에테르 1e30개 보유 | 미래 확장 |

L2의 N은 미정이다. 획득 누계와 현재 잔액을 별도로 관리한다. 자원을 소비해도 해당 회차의 획득 누계가 감소하지 않는다. L4는 실제 보유량을 검사한다.

### 7.2 L1 회귀

조건을 만족한 후 원하는 시점에 모험 시작으로 돌아간다. 시간 파편 보상은 해당 회귀 회차의 최대 진행 스테이지, 레벨, 플레이어 스펙에 비례하도록 정한다. 스펙의 측정 항목, 순간 버프 적용 여부, 정산식은 미정이다.

회귀 업그레이드, 상위 프레스티지 업그레이드, 영구 보존 요소를 제외한 진행을 초기화한다. 기본적으로 장비는 초기화되며 아래 업그레이드로 보존한다.

| 업그레이드 | 효과 |
|---|---|
| 물질 간섭 | 장착한 장비를 유지한 채 회귀 |
| 패러독스 | 인벤토리를 유지한 채 회귀 |

장비 보존은 아이템 인스턴스 보존을 뜻한다. 레벨 1에서 고레벨 장비를 계속 활성화할 수 있는지, 장착 제한으로 비활성화할지는 미정이다. 패러독스가 임시 획득함까지 보존하는지도 별도 결정한다.

### 7.3 L2 환생

축적된 시간의 힘으로 신체를 재구성하고 시간을 되돌린다. 이번 환생 회차에 얻은 시간 파편에 비례해 에테르를 얻는다.

환생 트리는 탐욕, 모험 등의 파트로 구성한다. 분기는 있지만 각 파트의 진행은 비교적 선형적이다. 던전앤파이터는 분기 형태 참고다. 회귀보다 큰 능력치 성장, 편의, 콘텐츠, 일부 자동화를 제공한다.

장비는 환생 시 초기화하며 **공허 창고에 넣은 아이템**은 다음 환생까지 가져간다. 환생 트리의 관련 노드로 창고 칸 수가 증가한다. 회귀 보존 업그레이드가 환생의 장비 초기화 규칙을 덮어쓰지 않는다.

### 7.4 L3 개변

자신뿐 아니라 공간과 세계 환경을 개변한다. L3 진입 이후에는 **회귀와 환생을 실행할 수 없다**.

개변으로 얻은 매터를 기반으로 **매터 → 에테르 → 시간 파편**의 자동 생산 체계가 작동한다. 대규모 자동화, 편의성, PoE식 연결 노드 성장을 제공한다.

다음은 미정이다.

- L3의 이번 회차를 최초 진입 전 전체 누적 / 마지막 개변 이후 누적 중 어떻게 정의할지
- 개변을 반복 실행할 수 있는지, 가능하다면 이후 조건과 초기화 범위
- 매터 지급식, 상위 생산원의 소비 여부, 생산 계수와 업그레이드
- 자동 생산을 백그라운드와 오프라인에서 처리할지
- 기존 환생 트리와 회귀 업그레이드의 보존 또는 재구매 방식

L3의 누계가 불명확한 상태에서 마지막 L2 환생마다 에테르 누계를 지우는 구현을 기본값으로 채택하지 않는다.

### 7.5 보존 / 초기화 매트릭스

| 항목 | L1 회귀 | L2 환생 | L3 개변 |
|---|---|---|---|
| 현재 레벨 / 경험치 / 지역 진행 | 초기화 | 초기화 제안 | 미정 |
| 스탯 투자 / 레벨 기반 스킬 습득 | 초기화하고 재성장 | 초기화 제안 | 미정 |
| 골드 / 강화석 / 혼돈 파편 | 기본 초기화, 별도 보존 업그레이드는 미정 | 초기화 제안 | 미정 |
| 장착 장비 | 물질 간섭으로 보존 | 공허 창고에 넣은 아이템 보존 | 미정 |
| 인벤토리 | 패러독스로 보존 | 공허 창고 외 초기화 | 미정 |
| 시간 파편 잔액 | 유지 + 이번 회귀 정산 | 초기화 여부 미정 | 생산 가능, 기존 잔액 처리 미정 |
| 회귀 업그레이드 | 유지 | 보존 범위 미정 | 보존 범위 미정 |
| 에테르 / 환생 트리 | 유지 | 정산과 트리 성장, 기존 잔액과 트리 유지 제안 | 보존 범위 미정 |
| 매터 / 개변 노드 | 상위 진입 후 L1 불가 | 상위 진입 후 L2 불가 | 반복 정책 미정 |
| 마스터리 경험치 / 레벨 | 영구 유지 | 영구 유지 | 영구 유지 |
| 닉네임 / 설정 / 도감 / 최고 기록 | 유지 제안 | 유지 제안 | 유지 제안 |

마스터리는 프레스티지 전반에서 유지한다. L4의 세부 초기화도 추후 설계하되 마스터리 영구 보존 원칙을 따른다.

실행 전 획득 재화, 잃는 아이템, 보존 아이템, 구매 가능한 성장의 미리보기를 제공한다. 보상과 초기화는 하나의 저장 단위로 처리한다. L2에서 미정산 L1 보상을 자동 포함할지는 미정이다.

## 8. 스탯 / 직업 / 스킬 / 페르소나 / 마스터리

### 8.1 스테이터스 포인트 | 확정 및 채택 초안

레벨업마다 3포인트를 지급한다. 레벨 1은 미배분 0으로 시작하며 레벨 50까지 147포인트다. 초기 능력치와 레벨 성장치는 별도다.

| 스탯 | 1포인트 효과 |
|---|---|
| 힘 | 물리 공격력 +1 / 물리 방어력 +0.1 |
| 민첩 | 속도 +0.3 / 치명타 확률 +0.03%p |
| 지능 | 마법 공격력 +1 / 최대 MP +2 |
| 체력 | 최대 HP +8 / 물리 방어력 +0.25 / 마법 저항력 +0.15 |
| 정신 | 최대 MP +4 / 마법 저항력 +0.25 / 초당 MP 회복 +0.05 / 직접 회복 스킬 효과 +0.3%p |

마을에서 무료 재분배한다. 각 포인트의 추가 수치와 최종 능력치를 같이 보여준다. 정신의 회복 보너스는 직접 회복 스킬에 적용하고 포션과 흡혈은 각 규칙에 따른다.

### 8.2 직업 | 확정

메인 클래스 1개와 서브 클래스 1개를 선택한다. 두 클래스의 배운 액티브와 패시브를 모두 사용한다. 추후 기본 클래스 스킬 강화는 메인 클래스 소속에만 허용한다.

| 클래스 | 정체성 |
|---|---|
| 전사 | 물리 공격, 높은 방어와 지속력, 다수전 |
| 마법사 | 마법 고화력과 유틸, 낮은 방어 |
| 궁수 | 물리 공격, 중하급 생존, 치명타와 속도, 단일전 |
| 도적 | 물리 공격, 낮은 생존, 쌍수와 속도, 온힛과 디버프 |
| 성직자 | 마법 공격, 매우 높은 생존, 회복과 유틸, 상대적으로 낮은 직접 공격 |

메인과 서브에 같은 클래스를 선택할 수 있다. 동일 스킬을 한 번 배우고 한 번 표시하며, 동일 클래스 공명으로 해당 클래스의 피해 / 회복 / 보호막량 +20%를 초안으로 둔다. 패시브를 두 번 중복 적용하지 않는다. 효과 시간, 행동 횟수, 쿨타임 같은 규칙 수치는 스킬마다 공명 효과를 명시한다.

클래스 조합은 순서 무관 15종의 페르소나를 결정한다. 전사+마법사와 마법사+전사는 같은 마검사지만 강화 가능한 기본 스킬이 다르다. 마을에서 직업 변경과 관련 스킬 포인트 환급을 지원한다. 사용할 수 없는 슬롯을 해제하고 변경 결과를 미리 보여준다.

### 8.5 페르소나의 고유 규칙 | 승인된 방향

페르소나는 전투 스타일을 크게 바꾼다. 고유 효과가 레벨 50부터 작동하고 액티브 4개와 패시브 2개가 이를 지원한다. 액티브 해금은 50 / 60 / 75 / 90, 패시브는 55 / 80레벨이다.

| 조합 | 페르소나 | 고유 효과 | 운용의 변화 |
|---|---|---|---|
| 전사 + 전사 | 바바리안 | **폭주**. 가하거나 받은 피해로 분노를 쌓고 최대치에서 폭주. 단일 근접 공격을 전체 공격으로 확장하고 처치로 시간을 연장 | 분노 준비 후 연쇄 처치로 폭주 유지 |
| 전사 + 마법사 | 마검사 | **검과 주문의 교차**. 물리와 마법 스킬을 교대로 쓰면 다음 반대 계열 강화. 일정 교차 후 마지막 두 스킬을 게이지 소모 없이 재현 | 강한 스킬 두 개가 재현 구간에 오도록 순서 설계 |
| 전사 + 궁수 | 척후병 | **추가 행동권**. 표식 대상 처치 시 즉시 추가 행동과 표식 이전. 추가 처치로 연쇄. 보스는 표식 누적 피해 기준으로 발동 | HP를 준비해 처치 연쇄 시작 |
| 전사 + 도적 | 광전사 | **죽음의 유예**. HP 0에서 잠시 전투 지속. 그동안 피해로 생존량을 채우면 회복하고 생환. 재사용 대기 적용 | 죽기 직전 극딜을 준비하고 유예 중 공격으로 생존 |

### 8.7 고유 효과의 경계 조건

- 복제와 재현은 원본 시전 이력을 갖는다. 복제에 의한 복제와 무제한 재귀를 차단한다.
- 척후병 추가 행동은 새 처치나 새 보스 피해 이정표마다 한 번 발생한다. 동일 사건의 재처리로 추가 행동을 지급하지 않는다.
- 시간 절단에서 기록하는 피해, 온힛 발동, 죽음 판정과 정산 순서를 명시한다.
- 치명타, 흡혈, 쌍수, 보호막, 회복 증폭, 클래스 공명, 마스터리의 각 고유 효과 적용 여부를 데이터로 표시한다.
- 현자의 자원 교환, 대사제의 회복 피해 전환 등은 자기 자신을 끝없이 재발동시키지 않는다.
- 보스의 처형과 게이지 정지 효율, 내성, 예외는 미정이다.
- 유효 회복은 실제 채운 HP, 실제 흡수는 실제로 막은 피해를 뜻한다. 대사제의 초과 회복은 별도의 명시된 전환 경로다.

## 9. 주요 화면과 모바일

마을, 던전 선택, 전투, 캐릭터, 장비와 인벤토리, 전술과 스킬, 대장간, 프레스티지, 마스터리, 기록과 설정을 제공한다.

전투에서 닉네임, 레벨, HP / MP, 행동 게이지, 공격 대상, 적 행동 예고, 포션 두 칸, 현재 스킬, 기본 재화, 필요한 페르소나 고유 상태를 확인한다. 고유 상태는 현재 페르소나에 필요한 항목만 표시한다.

모바일은 360 CSS px부터 가로 넘침 없이 사용하도록 검증한다. 주요 터치 영역은 44×44 CSS px 이상, 상세 정보는 탭과 키보드로도 열 수 있어야 한다. 기기 안전 영역과 화면 회전을 고려한다. 자세한 레이아웃과 네온 색 사용은 개발 가이드라인을 따른다.

## 10. 저장과 기술 방향

초기 싱글플레이는 브라우저 저장과 JSON 내보내기 / 가져오기를 기본안으로 둔다. 현재 진행, 프레스티지 누계, 영구 성장, 설정을 구분하고 저장 버전을 관리한다.

전투는 동일 입력과 난수에서 동일 결과를 내는 코어로 구성한다. UI는 공통 계산 결과를 표시한다. 장비와 재화 변경, 보상 지급, 프레스티지 실행은 중간 상태를 노출하지 않는다. 큰 수 계산은 L4의 1e308과 그 이후 연산을 지원하는 자료형을 전제로 설계한다. 특정 라이브러리 선택은 구현 단계에서 결정한다.

## 11. 개발 순서 | 제안

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| A | 1개 마을과 던전, 적 1~3명, 네온 도형 전장, 전술, 포션, 저장, 기본 직업과 스탯 | 전투부터 장비 교체와 성장까지 연결 |
| B | 9슬롯, 품질과 잠재능력, 강화와 재련, 분해와 재설정, 마스터리, 세 번째 마을 10번째 던전까지 | 레벨 50 도달과 첫 회귀 조건 검증 |
| C | L1 보존 업그레이드, 5개 기본 직업과 15개 페르소나의 고유 효과와 첫 스킬 | 첫 회귀와 페르소나 중 선택하는 경험 검증 |
| D | 고레벨 페르소나 스킬, L2 트리, 공허 창고, 콘텐츠 확장 | 환생 정산과 보존을 포함한 전체 주기 검증 |
| E | L3 생산 체계와 노드, 후속 룬 콘텐츠 | 하위 프레스티지 종료 후 성장 전환 검증 |
| 이후 | L4 창조 | 별도 기획 후 구현 |

영웅 / 전설 / 신화의 실제 드롭 구간은 콘텐츠에 맞춰 정한다. 개발 단계에서 기능을 나누더라도 합의한 장기 기획에서 임의로 제거하지 않는다.

Everkin은 규칙 / 데이터 / UI의 분리, 공통 캐릭터와 재화 요약, 개체별 처치 보상, 저장 구조를 참고한다. 해당 프로젝트의 화면 스타일과 고유 수치를 그대로 이식하지 않는다. [Everkin](https://github.com/Deuwel/Everkin)

Soda Dungeon 2는 조건과 우선순위 전술, 소울나이트 프리퀄은 두 직업 조합, The Tower는 네온 UI, 던전앤파이터는 환생 트리의 선형 분기, Antimatter Dimensions는 생산 계층, Path of Exile은 개변 노드 구조의 방향 참고다. 이 문서는 각 게임의 실제 구현을 재현한다는 사양이 아니라 RE:RPG에서 합의한 자체 규칙을 정의한다.
