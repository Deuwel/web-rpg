# A 단계 | 전투와 파밍

## 첫 플레이

1. 윈드해븐에서 **탐험 시작**을 누릅니다. 플레이어와 각 적은 자기 속도로 게이지를 채웁니다. 전장의 적을 누르면 기본 공격과 단일 대상 스킬의 표적이 바뀝니다.
2. 일반 전투 승리 후 다음 무리가 자동으로 등장합니다. 적을 처치하는 즉시 골드와 경험치를 얻고 장비 획득을 판정합니다. 패배하거나 도중에 귀환해도 이미 얻은 보상은 유지됩니다.
3. **마을 귀환 → 가방 → 장비**에서 착용 전후의 능력치를 비교합니다. 장비를 잠그면 판매가 차단됩니다. 가방 60칸이 모두 차면 초과 보상은 임시 획득함에 남고 전투가 멈춥니다.
4. 레벨마다 받은 3포인트를 **스탯 상세**에서 분배합니다. 레벨 5부터 전사를 선택하고 레벨마다 SP를 1씩 받습니다. 처음 2 SP가 모이는 레벨 6에 가르기를 배울 수 있습니다.
5. 같은 깊이에서 일반 전투 10승을 거두면 마을에서 **감시자 도전**이 열립니다. 감시자는 세 번째 행동마다 강타를 준비합니다. 보스를 처치하면 고급 이상 장비 한 개를 받습니다.

## 전술과 포션

세 슬롯에 습득할 스킬을 미리 등록할 수 있습니다. 자기 차례마다 실제로 사용할 수 있는 스킬만 고릅니다. 우선순위 숫자가 낮은 스킬이 먼저입니다. 동순위에서는 조건을 만족한 스킬이 무조건 스킬보다 앞서며, 동률이면 위쪽 슬롯부터 사용합니다. 예를 들어 함성이 적용된 상태에서 가르기와 휩쓸기의 우선순위가 같고 적 3명이 살아 있으면, 적 3명 이상 조건의 휩쓸기가 먼저입니다. MP나 쿨타임 때문에 쓸 수 없으면 다음 후보로 넘어갑니다. 수동 예약은 다음 자기 차례에 한 번 적용됩니다.

설정에서 포션 두 칸을 등록하고 마을에서 보충합니다. 포션은 전투 시간 기준으로 종류별 재사용 대기시간을 가지며 행동 게이지를 소비하지 않습니다. 상세 창을 열면 전투가 일시정지되고, 창을 닫은 뒤 **계속하기**로 재개합니다.

## 플레이테스트 범위와 수치

| 항목 | 이번 빌드 |
|---|---|
| 지역 | 윈드해븐과 변두리 들판 | 
| 탐험 깊이 | 입장 레벨 1 / 5 / 10 / 15, 깊이별 보스 승리 기록 |
| 캐릭터 | 최대 Lv.20, 전사 액티브 3종과 패시브 1종 |
| 장비 | 무기 / 갑옷 / 목걸이, 템플릿 6종, 일반 / 고급 / 희귀. 품질 50%, 강화 +0 |
| 보상 | 일반 장비 드롭 28%, 보스 장비 드롭 100%, 강화석 6%, 혼돈 파편 일반 0.2% / 보스 15% |
| 회복 | 일반 승리 후 최대 HP의 6% 회복. 레벨 상승과 재입장 시 HP와 MP 회복 |
| 포션 | HP 45% 회복 / 12초 / 12골드, MP 50% 회복 / 18초 / 10골드 |

전투 한 주기를 검증하기 위한 초기 수치입니다. 고레벨 콘텐츠, 장비 강화와 재련, 잠재능력, 서브 직업과 페르소나, 마스터리와 프레스티지는 전체 기획서에 정의된 후속 구현 범위입니다.

## 소스와 검증

- `src/data.js`에 데이터와 스킬 조건이 있습니다.
- `src/game.js`에서 시간 진행, 전술 선택, 피해, 보상, 성장과 장착을 계산합니다.
- `src/ui.js`가 입력과 표시를 담당합니다. 전장과 장비 비교는 같은 능력치 계산을 사용합니다.
- `src/storage.js`가 저장 형식 v1과 파일 검증을 담당합니다. 진행 중 탭을 숨기면 일시정지합니다. 같은 브라우저의 두 번째 탭은 읽기 전용입니다. 자동 저장을 제공하지 못하는 환경은 화면에 안내합니다.
- `npm test`로 동률 전술, 죽은 적의 행동 취소, 광역 처치 보상과 임시 보관, 포션 쿨타임, 보스 조건, 성장, 장비, 저장 복구와 큰 수 연산을 재현할 수 있습니다.
